# Changelog

## 0.1.0-preview.5

- Export portable recipes as Lenso Code module directories through `@lenso/design/code`.
- Distribute `@design/button` 0.1.0 for Solid with Tailwind, StyleX and CSS Modules through Code 0.3.8.
- Verify selection, rendering, keyboard activation and upgrade conflict handling across three consumer projects.

## 0.1.0-preview.4

- Register all 13 author and consumer commands under `lenso design` with the npm extension on hosts supporting structured process handlers.
- Review local file replacements individually through Lenso prompts or JSON answers when upgrading generated components.
- Lenso 1.1.2 supports the four Wasm contract commands. The npm executable remains available for authoring on that host.

## 0.1.0-preview.3

- Add portable recipe parts, a themed Solid Dialog, rendered theme diagnostics and component-scoped source usage.
- Discover imported JSX component usage without a design contract. Select bundled registry items and delegate installation, upgrade previews and diffs to shadcn.
- Verify the three native Dialog targets, portal counterexamples, keyboard focus and reuse in an unannotated Lenso Docs project.

## 0.1.0-preview.2

- Share initialization, multi-axis selection, profiles, mappings and declared usage evidence across the contract tools. Add the v1 schema, migration and impact commands.
- Add a DTCG Resolver input, native Solid recipe outputs, a scoped upstream Separator example, a Docs collection and a DESIGN.md front-matter adapter.
- Verify the portable targets in Chrome with UI SDK keyboard behavior and resolved styles.

## 0.1.0-preview.1 - 2026-11-24

- Introduce the version 1 declarative Design contract for live token resolution, inspection, validation, and queries.
- Distribute a Wasm extension for Lenso CLI 1.1.2. The extension reads the project's design.json through an explicit read grant.
- Use the same Wasm kernel for declarative operations in the standalone CLI.
- Provide optional TypeScript authoring tools for CSS, Tailwind, StyleX, and scoped shadcn Registry output.
